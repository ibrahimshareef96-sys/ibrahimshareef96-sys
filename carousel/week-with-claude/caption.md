## Before you post

1. Pick one version: `out/claude/` (Claude's campaign look) or `out/itqan/` (your teal and lime).
2. Read the five slides marked **confirm** in the README and make sure each one describes what you actually do.
3. Upload all 11 in order. They are already 1080 x 1350 (4:5), so don't let Instagram crop them.
4. Don't add Claude or Anthropic as a collaborator or use the Paid partnership label unless it is one. If any tool on these slides pays you or gives you an affiliate cut, disclose it.
